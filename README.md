## 🚀 Features

| Module | Description |
|--------|-------------|
| 🌐 Subdomain Enum | Discovers all subdomains |
| ✅ Live Host Check | Finds active hosts |
| 🔌 API Discovery | Finds hidden API endpoints |
| 🔐 CORS Scanner | Detects misconfigurations |
| 🔁 Open Redirects | Finds redirect vulnerabilities |
| 💾 Backup Files | Locates sensitive backup files |
| 🛡️ Security Headers | Scores security header quality |
| 🔒 SSL/TLS Check | Assesses SSL configuration |
| ☁️ Cloud Detection | Identifies cloud providers |
| 📧 Email Discovery | Finds exposed email addresses |
| 📂 Dir Listing | Detects open directories |
| 🕰️ Wayback Analysis | Historical URL analysis |

## 📦 Installation & Usage

```bash
# Clone the repository
git clone https://github.com/skymahnoor/bug-bounty-recon.git

# Go into the directory
cd bug-bounty-recon

# Give execute permission
chmod +x recon.sh

# Run the script
./recon.sh target.com
```
